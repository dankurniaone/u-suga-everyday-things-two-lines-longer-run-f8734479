Entry for the [make.fun bounty "Everyday Things, Two Lines, Longer Run"](https://make.fun/competitions/u-suga-everyday-things-two-lines-longer-run-f8734479).

`main.ts` (Node 22, stdlib only) writes a two-line explanation of a traffic jam to `/output/entry.txt`: line 1 explains it to a 10-year-old through one vivid analogy (a straw full of peas), line 2 says honestly what that analogy maps and what it leaves out. It validates the gate (1–400 characters, exactly two non-empty lines) and verifies the round-trip by reading the file back.

Run it with:

```sh
node main.ts
```
